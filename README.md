# Ultimate Draft Order

A mobile-first, single-page tool for building a personal "ultimate draft order" for an NBA fantasy H2H points league, by blending up to 12 pasted-in ranking sources with your own manually reordered draft list.

No backend, no build step. Open `index.html` directly in a browser, or serve the folder with any static file server.

## Data & privacy

By default, all data (sources, parsed rankings, drafted status, and your draft list) is stored **only in this browser's `localStorage`**, on this device. There is no server and nothing is uploaded anywhere.

**This means, unless you turn on GitHub Sync (below):**
- Your data does not sync across devices or browsers.
- Clearing your browser's site data/history for this page (or using a different browser/profile) will lose it.
- Your drafted players, My Team, and tags are protected several ways (see "Protecting your draft data" below) — but keep GitHub Sync connected, it's the main safety net.

### GitHub Sync (optional)

The Sources tab has a "GitHub Sync" card. Paste in a **fine-grained GitHub Personal Access Token**, scoped to only this repo with `Contents: Read and write` permission, and:
- Your data loads from `data/draft-state.json` in this repo every time the app opens on that device.
- Every change you make (debounced by a couple of seconds) pushes an update back to that file — as an actual git commit.
- Connect the same repo with a token on another device (phone, another browser) and it'll load the same data.

Notes:
- The token is stored **only in that browser's local storage** — it is never written into the code or the repo, so it isn't exposed by the fact that this site is public.
- Because saves are real commits, active use (lots of dragging/reordering) will add a fair number of commits to this repo's history over time.
- Saving requires a network connection and GitHub being reachable; without a token, the app works exactly as before (local-only).
- If you reload right after a big change (e.g. uploading Season Stats) and the save hadn't finished reaching GitHub yet, the app notices and **merges** it with what's on GitHub (see below) instead of either side overwriting the other.

#### Protecting your draft data

The whole app state is one file, so a device with stale data could once overwrite a newer version (this actually happened: a stale copy wiped the drafted players and My Team). It can't any more:
- **Pull before push.** Nothing is sent to GitHub until the app has loaded the current version first. Unsynced changes left on a device are *merged* with GitHub's copy, never pushed over it.
- **Merge, don't overwrite.** The app remembers what GitHub held at the last sync. If this device and GitHub have both changed since, they're combined: a section only one side changed takes that side's version; drafted players, My Team, targets, do-not-draft, breakout/sleeper tags, notes, and saved searches are merged entry by entry (something only counts as removed if you removed it on this device). With no history to go on, those lists are simply unioned, so nothing is lost. If GitHub rejects a save as out of date, the app pulls what landed, merges it, and only then saves again.
- **Wipe guard.** A save that would drop the drafted + My Team count to under half of what GitHub has (when that's 5 or more) is refused, with a "Sync paused" message in the Sources tab.
- **Local backups.** Snapshots of the drafted / My Team / tag lists are kept on each device (the fullest one is never discarded), taken automatically before anything replaces local data and as you draft.
- **New file name.** Since Oct 9 the app saves to `data/draft-state.json`. Any page still open from before running the *old* sync code (which could overwrite newer data with a stale copy — it did, twice) can only write to the old `data/state.json`, which nothing reads any more, so it can't hurt your data. If a device looks out of date, close the app completely and reopen it.
- **Recover Draft Data** (Sources tab, above Fake Mode): restore the lists from one of those local backups, or — with sync connected — browse the last 100 saves GitHub has of the state file, preview how many players each holds, and restore. Restoring only replaces the drafted / My Team / target / do-not-draft / breakout / sleeper lists, backs up what was there first, and doesn't touch sources or stats. Every save is also an ordinary git commit, so `git log -- data/state.json` / `git show <commit>:data/state.json` in this repo is a last-resort copy of everything.

## How it works

- **Draft List tab** — your own editable, drag-to-reorder list, shown the same way (combined rank average, name, position badge, tag emoji, every-10th divider, alternating row shades). It's seeded from the combined average the first time you use it, then persists independently — editing sources never silently overwrites it.
  - A search box filters the list to players matching what you type (tap the ✕ to clear it).
  - A source filter controls which sources feed the average shown next to each name. Changing it automatically resyncs the list to the newly-filtered average — there's no separate Reset button, and it's easy to undo by dragging things back. A position filter (PG/SG/SF/PF/C, all the same width) just narrows which players are shown, without touching the order.
  - A source whose "Score" column is a "Total" (last year or projected) starts **off** by default — a raw season/projected total skews a combined *average* of ranks the way a per-game average doesn't, so those opt in rather than opt out. A source whose Score is an "Average" (last year or projected) steps through **1x → 1.5x → 2.5x** as you tap it (each counts that many times as heavily in the combined average) — the chip turns a darker blue and shows "· 1.5x"/"· 2.5x", darkest at 2.5x. A 4th tap turns it off again. **Long-pressing** (about half a second) any source's chip (or square in Player Detail) turns on **iso mode**: only that source counts, so the ranks and combined number shown are just that one list's own — the chip reads "· iso" with a white outline. While in iso mode, long-pressing more sources adds them (as many as you like, all at 1x), and long-pressing one that's already isolated drops it. A plain tap on any chip — isolated or not — cancels iso mode and puts back exactly the filters you had on before going in (that tap does nothing else). Draft List's chips and Player Detail share this, and iso carries between them when you open or close a player. Every other source just has the plain on/off toggle it always had.
  - Each position chip also shows how many of the best remaining undrafted players hold that position — e.g. "PG 4" — scoped to a pool size you pick from the dropdown next to the chips (10/20/30/.../100). That count re-ranks live off the current source filter, so it always reflects whichever sources are checked. A position's chip outlines orange once its share of the pool is 25% or lower, and red at 17% or lower, so you can see a position running thin before you're stuck.
  - A **Team** row sits right under the position chips and works like Smart Search: one full-width chip that opens a screen listing every team found in the Data List (a 2-column grid of tiles, same style as Player Detail's source squares), each showing how many of that team's players are already drafted. At the bottom, a condition — "Highlight teams [N] lower than average" — fills in blue every team whose drafted count is at most the average per team minus N (average 2.4 and N = 1 highlights teams with 1 drafted or fewer), so the teams you've drafted from least stand out while the rest stay visible; the average is shown under it, and N is remembered across uses. Tap as many teams as you like (a white outline and ✓ when picked) and hit Apply — the list then shows only players on those teams, the chip turns blue and reads "Teams: DAL, LAL", and a ✕ beside it clears the filter. It stacks with the position chips, Smart Search, and the search box (a player's team is their Data List team, so players with no Data List entry drop out while it's on).
  - **"Lock List"** sits on its own row, just under the position chips (drafted players are always hidden from this list — see them on Draft Board), with **"Next Pick"** beside it. Lock List stops the filters from reordering the list: changing the source filters (or filtering from Player Detail) still updates every combined rank shown, but the players stay exactly where they are. You can still drag players by their handles while it's locked. Tap it again to unlock — the order stays as it is until the next filter change, which resyncs the list to the combined average again. The lock is remembered between uses (and syncs with the rest of your data). On to the second button: Turn the latter on and blue "— Pick 18 —" markers (same look as the 10/20/30 dividers, in blue) show where each of your upcoming turns in a snake draft falls — every one that fits in the list, e.g. picks 3, 18, 23, 38, 43… Each sits right after the players who will likely be gone before you pick, and they all shift as you mark players drafted (when it's your turn, that marker sits at the very top). A marker takes the place of a numeric divider if they coincide; with filters on, each lands after however many of those players are still showing (picks that collapse onto the same row share one label, "Pick 18 · 23"). It's set up for a 10-team league where you pick 3rd — those are the `pickSlot` and `leagueSize` values in the saved state (defaults 3 and 10). The toggle is remembered.
  - Drafted players are hidden here too, but keep their spot in the order so un-drafting restores it. Tap a player to open their detail view and mark them drafted from there.
  - A health emoji shows on the right of a row when Season Stats (Sources tab) supports it — 💪 for a player who played 65+ games in all 3 uploaded seasons, 🚑 for one who played 54 or fewer games in at least 2 of them. A trend emoji (⬆️ up, ⬇️ down) shows alongside it for a player whose PTS/TRB/AST/BLK/STL/FT moved the same way, each by at least that category's own minimum amount (PTS/TRB/FT 1, AST 0.5, BLK/STL 0.25) — moving by double that minimum (or more) is worth 2 points instead of 1, capped there so one huge swing in a single stat can't qualify on its own. Either of two ways earns it: at least 5 points' worth moved the same way just last season on their own, or it's sustained over 2 years — at least 3 points' worth moved the same way from the oldest season to the middle one, at least 3 points' worth again from the middle season to the most recent one, and at least 2 categories are common to both (they don't have to be the identical ones each year). Both shown only in Draft List, computed fresh from whatever seasons are uploaded (a season with no file, or where this player has no row, just doesn't count toward either).
  - **Smart Search** (its own button right below the search box) opens a structured deep-search overlay: "Find a player with [metric A] [Better Than / Worse Than] [metric B], in at least [N] ranks." Metrics are Combined Rank (using whichever sources Draft List's own filter currently has checked) plus each individual source's own rank — the second dropdown always excludes whatever the first one is set to. "Better Than" compares rank numbers directly: metric A is at least N ranks better (lower) than metric B. For example, "2026 Average Better Than Combined Rank, at least 15 ranks" finds players who ranked well on 2026 Average but have since fallen at least 15 spots in the current Combined Rank — a quick way to spot decliners (or, flipped, breakouts). Once a search runs, the button becomes "Edit Search" (reopens it pre-filled) plus a ✕ that clears it. Tapping any of the other quick filters (a source chip or a position chip) also clears an active Smart Search, since narrowing them both at once would be ambiguous — but tagging a player or typing in the plain search box does not.

    The overlay's top half is **Saved Searches** — a 2-column grid of tiles (same style as Player Detail's source squares), one per saved search plus a trailing "+ Add a Search" tile. Tapping a tile commits it immediately — applies those criteria and closes, the "go back to a search you set up before" shortcut. Its small ✏️ instead opens an editor: title at the top, then the same metric/direction/ranks fields as the plain form below the grid, fully editable, plus "Save Search" (saves and returns to the grid) and "Delete Search". "+ Add a Search" opens that same editor blank. The plain "Find a player with..." form still sits below the grid exactly as before Saved Searches existed — no title, just an ad-hoc one-off query that applies without saving.
- **My Team tab** — the roster of players you've marked "Drafted By Me" (from a player's detail view), in the order you drafted them, each shown as the same card as the other lists (combined rank average with the default source weights, name, position badge, tag emoji). Five small counters at the top show how many players you have eligible at each position (PG/SG/SF/PF/C) — a player listed under multiple positions (e.g. "PF, SF") counts toward each.
- **Draft Board tab** — every player marked drafted by any means (not just "Drafted By Me" — the plain "Mark Drafted" button too), in the order they were actually drafted. That order is fixed; it's a record of the draft, not something you reorder. It has no filters — the combined rank shown next to each name always uses the default source weights. Each entry has its overall pick number to the left, outside the card; picks you made yourself ("Drafted By Me") are blue; and a "— Round N —" divider (same style as the dividers in Draft List) starts each round of one pick per team (`leagueSize` in the saved state, default 10). Otherwise shown the same way as the other lists (name, position badge, tag emoji, alternating row shades) — except the health/trend emoji, which are Draft List only.
- **Notes tab** (left of Sources) — free-standing notes, separate from the per-player notes box in Player Detail. "+ Add Note" opens a text box (Save / Cancel); each saved note shows its text with Edit and Delete (Delete asks first; saving an edited note with its text cleared offers to delete it). Newest notes first; an edited note keeps its place. Saved on-device and synced to GitHub like everything else; Fake Mode leaves them alone.
- **Sources tab** — add up to 12 sources. Each has a name, an optional reference URL (shown as a link only, never fetched), what its "Score" column means (last year avg/game, last year total, or a this-year projection), and a paste-in box for raw ranked player text. Once saved, a source collapses to a summary card — hit "Edit" to paste a new list or change its details, or "Cancel" to back out without saving. Drag a card by its grip bar to reorder sources (this controls, e.g., which source's data wins for a player's positions, and display order in the player detail view).

  Paste format: one player per block, separated by a blank line —
  ```
  4
  LeBron James
  PF, SF
  57.2

  5
  Nikola Jokic
  C
  56
  ```
  Rank and Name are required; Positions and Score are each optional.

  Picking **ADP (Average Draft Position)** as the Score type switches the paste format entirely — an ADP list's order doesn't correlate with its score the way a rank does (the #1 player by ADP order might have an ADP score of 1.6, not 1), so there's no rank line at all, just Name then the ADP score, one player per block —
  ```
  LeBron James
  24.7

  Nikola Jokic
  1.6
  ```
  The ADP score itself is what feeds the combined average when this source is checked (not the block's position in the list), and it's what shows in place of a rank number everywhere this source's value is displayed — the source square in Player Detail, Smart Search's per-source metric, etc.

  Below the sources sits the **Data List** — a single, separate list that's never part of any ranking (it doesn't feed the combined average, the source filter, or the per-source grid in player detail). It's just extra per-player info to show in the player detail view — currently age and team (height is parsed too but not shown anywhere yet). Paste format is simpler than a ranking source's — no rank: one player per block, Name/Age/Team/Height, with Team and Height each optional —
  ```
  Santi Aldama
  25
  DAL
  7'0"

  Nikola Jokic
  30
  ```

  Below that sits **Season Stats** — 3 fixed upload slots (not a paste box) for the last 3 seasons' per-game stats, also never part of any ranking. Each slot has a label (e.g. "2025-26") and a file picker; pick the `.xls` file Basketball-Reference's "Per Game Stats" page exports (Share & Export → Get table as Excel) — it's actually an HTML table under the hood, so the browser reads it directly with no upload or external service involved. Whatever columns that export has (Team, GP, GS, MPG, full shooting splits, rebounds/assists/steals/blocks/TOV/PF/PTS, Awards, etc.) are carried straight through — except Age and Position, dropped since they're already shown elsewhere (Data List, the position badge); a player traded mid-season is collapsed to their one combined-season line (their Team shows as "2TM"/"3TM"/etc. for that season). "Clear" removes an uploaded season.

  At the very bottom of the Sources tab is **Fake Mode** — a throwaway sandbox for practicing against heavily scrambled data. Entering it gives each player one big random shift of 20-100 (up or down) that hits their number on every list they're on, plus a smaller independent wobble of up to 15 per list; each list is then re-ranked by the shifted values and its own original numbers (1, 2, 3… or the real ADP scores) dealt back out in that order, so every list is still a clean ranking while its players have moved around a lot. Because a player's shift lands on all their lists together it survives the averaging, and on top of that every player's combined rank gets a further random 5-15 either way (so it can dip below 1). Last seasons' numeric stats shift by a random +1.5 or -1.5 (never below 0; percentages, team, and awards are left alone, and games cap at 82), and all Breakout/Sleeper/Target/Do Not Draft tags are cleared. The Draft List order is re-seeded from the scrambled combined rank so the list matches. An orange banner shows across the top the whole time. Nothing done in Fake Mode is saved to this device or synced to GitHub — exit it (or just reload) and your real sources, filters, tags, drafted players, and order are exactly as you left them. It re-rolls the randomness each time you enter.

Player names are matched across sources (and the Data List) by normalizing them (case, accents, punctuation, Jr./Sr./III-style suffixes).

Tapping a player opens a detail view. Up top, their name (with a position badge — same style as the list rows' — to its right, sized to match the name's own row height, and their health/trend emoji — same 💪/🚑/⬆️/⬇️ as Draft List, if Season Stats supports any — right after that, then 🔁 if Season Stats' most recent season shows a team change — either that season is itself a multi-team code, or it differs from the Data List's current team) and, below that, their age from the Data List — with their team alongside it when known, as "25 · DAL" — or "Age unknown" if they're not in the Data List at all; whenever 🔁 shows, their last season's team follows in parens, e.g. "25 · DAL (MEM)". Next, their combined rank average (based on whichever source weights are active in the tab you opened it from) and four tag toggles share a row (so the Combined Rank box is a bit narrower): ⭐/🌟 Breakout, 🥱/😴 Sleeper (each tap cycles untagged → level 1 → level 2 → untagged), 🎯 Target, and 🚫 Do Not Draft (both plain on/off toggles). A toggle turns solid blue while tagged — this is the only place you can set these; list rows just display whichever emoji ends up active, on the right of the row. Below that sits a free-text notes box — no title, just an "Add notes" placeholder — 2 lines tall by default and growing with whatever you type, saved per player as you go. Below that, one square per source — every source you've added, not just the special avg/total ones. Each square shows that source's rank and, if it has one, its actual stat (e.g. an avg or total) side by side on the same row; squares for sources currently weighted in are highlighted blue, darker blue plus "· 1.5x"/"· 2.5x" for a boosted Average source. Tap a square to cycle that source's weight — the Combined Rank at the top updates live. Below the squares come the draft buttons — "Mark Drafted"/"Undraft" plus "Drafted By Me"/"Remove From My Team" (the latter both marks them drafted and adds them to the My Team tab in one step) — and below those, straight down the scroll (no button), every uploaded Season Stats season for this player (most recent first), each as its own block — with that season's **Avg** (average fantasy points per game under this league's scoring: FGM 2, FGA -1, FTM 1, FTA -0.5, 3PM 0.5, OREB 0.5, REB 1, AST 2, STL 4, BLK 4, TO -2, PTS 1; triple doubles (+3) aren't in the per-game export so they're not counted; hidden if a season's file is missing any of those columns) and **Tot** (Avg × games played) in blue under the title, each followed by its rank that season in parentheses — Tot on the line below Avg, e.g. "Avg: 70.6 (#1)" / "Tot: 4586 (#1)" — against every player in that season's file, then every stat that season's file has — PTS/TRB/AST/BLK/STL/FT are pulled up to right after MP instead of sitting wherever the file put them (FTA tags along right after FT, though it isn't one of those 6 itself), and each of those 6 gets its own ⬆️/⬇️ if it moved by at least its own minimum amount from the season before, or ⏫/⏬ if it moved by at least double that. Team sits at the very bottom of each block — and "No data" for a season where this player has no row (e.g. a rookie with no earlier seasons). Closing the view (✕, tapping outside, or Escape) carries that filter change back to the tab you opened it from, updating its chips and — in Draft List — resyncing the order to match.
